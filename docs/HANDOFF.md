# Перенос проекта «Бриз» (`briz.club`) на домашний компьютер

Документ содержит всё необходимое, чтобы развернуть репозиторий на новом ПК и за один шаг передать полный контекст новому AI-агенту.

---

## 1. Пошаговое развёртывание на домашнем ПК

```bash
git clone https://github.com/vrajina/briz-club.git
cd briz-club
```

Проект работает по принципу **Zero-Build** (чистые HTML, CSS, Vanilla JS — сборка и `npm install` для фронтенда не требуются). Доступны три способа запуска:

1. **Мгновенный просмотр без сервера:**
   Откройте в браузере `index.html`, `v2.html` или `new-year.html` напрямую (`file://`). Все стили, слайдеры, галерея, карта территории, калькулятор цен и модальные окна работают автономно.
2. **Локальный статический сервер (рекомендуется для разработки):**
   ```bash
   npx serve .
   # или через Python:
   python -m http.server 3000
   ```
3. **Полный локальный режим Vercel с функцией `/api/kontur`:**
   - Скопируйте `.env.example` в `.env.local` и впишите `KONTUR_WIDGET_TOKEN` (или подтяните из проекта Vercel):
     ```bash
     npx vercel link
     npx vercel env pull .env.local
     npx vercel dev
     ```
   - Деплой на продакшен-превью происходит автоматически при каждом `git push origin main` (сайт обновляется на `https://briz-club.vercel.app`).

## 3. Что НЕ хранится в Git (`.gitignore`)

Все **23 оптимизированных рабочих изображения и логотипа** в `assets/images/` уже закоммичены в репозитории — после `git clone` сайт полностью самодостаточен и ничего дополнительно копировать не нужно.

На рабочем ПК оставлены только тяжёлые исходники (исключены через `.gitignore`, чтобы не раздувать репозиторий). Если они когда-нибудь понадобятся в полном разрешении, их можно перенести вручную:

- `Бриз.zip` (~19,5 МБ) — архив исходных бренд-материалов.
- `Карта Отеля.png` (~5,1 МБ) — исходная иллюстрация карты территории (оптимизированная версия в Git: `assets/images/territory-map.jpg`).
- `фото внутри домов/` — 22 необработанных фото интерьеров (`IMG_8054.JPG`–`IMG_8093.JPG`); отобранные и сжатые кадры уже в `assets/images/house-*.jpg` и `assets/images/real-terrace.jpg`.
- `photo_2026-11-*.jpg` — 4 исходных фото территории.
- Локальные файлы окружения (`.env`, `.env.*`, кроме `.env.example`), `.vercel/` и `node_modules/`.

## 5. Открытый бэклог и возможные следующие шаги

1. **Утверждение основного варианта Hero (`v1` vs `v2`):** решить с заказчиком/командой, оставлять ли `index.html` (v1) или перенести в `index.html` стилистику `v2.html` (Forsthofgut), после чего при необходимости удалить неиспользуемую копию.
2. **Боевая отправка бронирований:** сейчас форма `#konturSimForm` показывает подтверждение сформированной заявки (`#konturSuccess`) и даёт прямую ссылку на `briz.club/booking?room-type=...`. Можно подключить:
   - либо реальный встраиваемый виджет Контур.Отеля в уже зарезервированный контейнер `#hotel-widget-container`;
   - либо серверлесс-обработчик отправки лидов в Telegram администратора / CRM через `/api/`.
3. **Тарифы на январь 2027:** в `js/app.js` (`getKonturNightPrice`) для `1–8 января 2027` стоит флаг `janClosed: true` с пояснением, что продажи на январь ещё не открыты — обновить сетку, как только откроются продажи в Контуре.
4. **Юридическая и контентная вычитка:** финально проверить реквизиты и формулировки ООО «Лагуна» в `LEGAL_DOCS` (`js/app.js`) и решить, нужно ли возвращать скрытые секции `#blog` / `#ugc`.

## 6. Как передать контекст новому AI-агенту

В корне репозитория создан файл [`AGENTS.md`](../AGENTS.md) — большинство AI-сред разработки (**Antigravity, Cursor, Codex, Windsurf**) читают его **автоматически** при открытии папки проекта.

Дополнительно, открыв проект на домашнем ПК в новом чате с агентом, отправьте ему следующий стартовый промпт:

```text
Мы перенесли проект редизайна сайта базы отдыха «Бриз» (briz.club) на этот компьютер.
Перед началом работы обязательно прочитай файлы `AGENTS.md` и `docs/HANDOFF.md` в корне репозитория — в них зафиксирована вся архитектура, карта файлов (`index.html`, `v2.html`, `new-year.html`, `css/styles.css`, `js/app.js`, `api/kontur.js`), правила синхронизации версий и кэш-бастинга (`?v=11`), реквизиты Контур.Отеля / Яндекс Карт / ООО «Лагуна», дизайн-инварианты и история итераций.
Подтверди кратко, что контекст загружен, и жди мою первую задачу.
```
