# База отдыха «Бриз» (`briz.club`) — интерактивный прототип редизайна

Рабочий адаптивный прототип обновлённой главной страницы базы отдыха «Бриз» на берегу Волги (с.п. Курумоч, Самарская область).

## Что реализовано в прототипе

- **Полупрозрачная шапка поверх баннера:** крупный оригинальный логотип и меню контрастного белого цвета с мягким верхним затемнением; при прокрутке шапка становится матовой светлой, а логотип автоматически переключается в бренд-зелёный `#3E5F46`.
- **Мобильная шапка:** крупный логотип, кнопка быстрого перехода к новогоднему предложению `НГ’27`, кнопка звонка и полнофункциональное бургер-меню с соцсетями.
- **Поиск и модуль бронирования:**
  - На десктопе — широкая панель поиска внизу поверх главного баннера ровно по ширине контентной сетки + парящий бар такой же ширины при прокрутке страницы;
  - На мобильных устройствах — форма сразу под первым экраном + компактная нижняя панель при прокрутке;
  - Интерактивное окно подбора в логике модуля **Контур.Отель** (выбор дат, гостей, категории коттеджа, подсчёт стоимости по будням/выходным и новогодним пакетам).
- **Коттеджи в 2 колонки одним блоком:** «Барн 70» (сразу видны оба варианта размещения: *Основное размещение до 2 гостей* и *С доп. местами 3–4 гостя*) и «Барн 130» (с камином и 3 спальными зонами) на реальных фотографиях в виде парных вертикальных слайдов.
- **Компактная Bento-фотогалерея:** разворот любого из 13 кадров в полноэкранный лайтбокс + интерактивные шоппинг-теги с перелинковкой на конкретные дома и услуги.
- **Интерактивный иллюстрированный план территории:** нарисованная схема базы вдоль берега Волги с кликабельными точками объектов (`1..9`) и синхронной легендой.
- **Услуги и прокат:** структурированный список-сетка карточек с фильтрацией по категориям (*Баня и чан*, *Зимний прокат*, *Вода и лето*).
- **Философия и Отзывы:** атмосферный драфт философии на фоне панорамы берега и блок отзывов Яндекс Карт (`5,0`, стилизованный макет + слот `YANDEX_ORG_ID` в `js/app.js` для автоматической подгрузки живого виджета); блоки «Блог» и «UGC» скрыты до второй итерации.

## Быстрый деплой на Vercel через GitHub

1. Создайте новый пустой репозиторий на GitHub (например, `briz-redesign`).
2. Свяжите локальный репозиторий и отправьте файлы (файл `.gitignore` уже настроен так, чтобы не публиковать архивы и исходные документы):
   ```bash
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/briz-redesign.git
   git branch -M main
   git push -u origin main
   ```
3. Зайдите на [vercel.com](https://vercel.com), нажмите **Add New → Project**, выберите ваш репозиторий `briz-redesign`.
4. В настройках проекта оставьте **Framework Preset: `Other`** и пустое поле `Build Command`, нажмите **Deploy** — через ~15 секунд получите рабочую ссылку вида `https://briz-redesign.vercel.app`.

## Подключение боевого модуля «Контур.Отель» в Тильде

Для переноса на боевой сайт `briz.club`:
1. В личном кабинете **Контур.Отель** (*Продажи → Бронирования с сайта → Виджет*) убедитесь, что в белом списке доменов указаны `briz.club` и при необходимости тестовый домен (`*.tilda.ws` или ваш `*.vercel.app`).
2. На странице в Тильде добавьте блок **`T123` (HTML-код)** и вставьте код виджета, связанный с контейнером `#hotel-widget-container`:

```html
<div id="hotel-widget-container"></div>
<script src="https://kontur.ru/hotel/widget/loader.js" async></script>
<script>
  window.addEventListener('DOMContentLoaded', function () {
    if (window.HotelWidget && typeof window.HotelWidget.add === 'function') {
      window.HotelWidget.add({
        type: 'horizontalBlock',
        appearance: {
          container: 'hotel-widget-container'
        }
      });
    }
  });
</script>
```
*(В прототипе уже предусмотрен контейнер `#hotel-widget-container` в модальном окне бронирования и хук для передачи выбранных дат и категории дома).*
