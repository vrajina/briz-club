# База отдыха «Бриз» (`briz.club`) — интерактивный прототип редизайна

Рабочий адаптивный прототип обновлённого сайта базы отдыха «Бриз» на берегу Волги (с.п. Курумоч, Самарская область), синхронизированный по данным с модулем бронирования **Контур.Отель** (`pms.frontdesk24.ru`, ID отеля `1292`).

## Структура и ключевые обновления

- **Три страницы:**
  - [`index.html`](index.html) — основная версия главной страницы (в стиле Forsthofgut): центрированная навигация без скролла, крупный логотип-герб по центру первого экрана, адаптивное фоновое видео (`hero-desktop.*` / `hero-mobile.*`), деревянная форма бронирования с чётким `2px` бордером (прилипающая при скролле и стыкующаяся над подвалом), полноширинная мобильная полоса бронирования без лишних рамок, сезонный блок Нового года, реальные фото и описания домиков `254819` и `254820`, Bento-галерея с лайтбоксом, карта территории с плавающей легендой, услуги, философия, отзывы Яндекс Карт (`227400604591`), FAQ и контакты;
  - [`v1.html`](v1.html) — резервная версия главной страницы с логотипом фиксированного размера слева в шапке (прежняя компоновка сохранена про запас, со старого URL `/v2` настроен редирект на `/`);
  - [`new-year.html`](new-year.html) — отдельная страница новогодней программы и вариантов размещения (`31 дек — 3 янв` и `3–8 янв`).
- **Реальные данные из Контур.Отеля и динамический коннектор ([`api/kontur.js`](api/kontur.js)):**
  - При деплое на Vercel серверлесс-эндпоинт `/api/kontur` опрашивает `POST https://pms.frontdesk24.ru/api/online/getHotelParams` и `getFreeRooms` с использованием переменной окружения `KONTUR_WIDGET_TOKEN`, обновляя названия категорий.
  - В локальном режиме (`file://`, обычный статический сервер или без переменной окружения) прототип мгновенно работает на встроенных данных и точной тарифной сетке в [`js/app.js`](js/app.js).
  - Для локального тестирования `/api/kontur` через `npx vercel dev` скопируйте [`.env.example`](.env.example) в `.env.local` и впишите `KONTUR_WIDGET_TOKEN`.
- **Отзывы и карта Яндекс Карт:** в [`js/app.js`](js/app.js) уже задан `YANDEX_ORG_ID = "227400604591"` — в секции `#reviews` автоматически монтируется живой `iframe` отзывов Яндекса, а в Hero отображается бейдж рейтинга.
- **Социальные сети и контакты:** ВКонтакте (`vk.com/briz.club`), Telegram (`t.me/briz_club`), телефон `+7 (937) 201-44-44`, почта `breezesmr@yandex.ru`, адрес 81-й квартал Большецаревщинского участкового лесничества, 5Б, юридические документы ООО «Лагуна» в модальном окне.

## Быстрый деплой на Vercel через GitHub

1. Репозиторий проекта: `https://github.com/vrajina/briz-club` (`.gitignore` исключает исходные архивы `Бриз.zip`, `BRIZE.zip`, сырые фото, `.env*` и `.vercel/`).
2. При необходимости живой синхронизации с Контуром добавьте в **Vercel → Settings → Environment Variables** переменную `KONTUR_WIDGET_TOKEN` (публичный GUID виджета бронирования).
3. В **Vercel** оставьте **Framework Preset: `Other`** и пустое поле `Build Command` — статические страницы и функция `api/kontur.js` подключатся автоматически (`https://briz-club.vercel.app`).
