# База отдыха «Бриз» (`briz.club`) — интерактивный прототип редизайна

Рабочий адаптивный прототип обновлённого сайта базы отдыха «Бриз» на берегу Волги (с.п. Курумоч, Самарская область), синхронизированный по данным с модулем бронирования **Контур.Отель** (`pms.frontdesk24.ru`, ID отеля `1292`).

## Структура и ключевые обновления

- **Две страницы:**
  - `index.html` — главная страница (полноширинный баннер 100%, форма бронирования по ширине контента, реальные фото и описания домиков `254819` и `254820`, полноширинная Bento-галерея на 14 фото, полноширинный план территории с плавающей сворачиваемой легендой, список услуг, полноширинный блок философии с правой плашкой, блок отзывов Яндекс Карт и обновлённые контакты);
  - `new-year.html` — отдельная страница новогодней программы и вариантов размещения (`31 дек — 3 янв` и `3–8 янв`).
- **Реальные данные из Контур.Отеля и динамический коннектор (`api/kontur.js`):**
  - При деплое на Vercel серверлесс-эндпоинт `/api/kontur` напрямую опрашивает `POST https://pms.frontdesk24.ru/api/online/getHotelParams` и `getFreeRooms` с токеном отеля (`25036D41-AC41-41C1-8010-C542D21DD847`), обновляя названия категорий и цены на выбранные даты.
  - В локальном режиме (`file://`) прототип мгновенно работает на точном слепке данных со страницы `briz.club/booking`.
- **Социальные сети и контакты:** реальные ссылки на ВКонтакте (`vk.com/briz.club`), Telegram (`t.me/briz_club`), телефон `+7 (937) 201-44-44`, почта `breezesmr@yandex.ru` и адрес 81-й квартал Большецаревщинского участкового лесничества, 5Б.

## Быстрый деплой на Vercel через GitHub

1. Создайте пустой репозиторий на GitHub (например, `briz-redesign`).
2. Подключите удалённый репозиторий и отправьте локальную ветку `main` (`.gitignore` исключает исходные архивы, референсы и сырые 16-мегабайтные фото):
   ```bash
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/briz-redesign.git
   git branch -M main
   git push -u origin main
   ```
3. В **Vercel** нажмите **Add New → Project**, выберите репозиторий `briz-redesign`, оставьте **Framework Preset: `Other`** и пустое поле `Build Command` — функции в папке `api/` (`api/kontur.js`) подключатся автоматически.

## Подключение живого виджета отзывов Яндекс Карт

В файле `js/app.js` выведена константа `YANDEX_ORG_ID`. Чтобы в секции `#reviews` автоматически подгружался интерактивный скроллящийся `iframe` от Яндекса (`https://yandex.ru/maps-reviews-widget/<ID>?comments`), впишите туда цифровой ID организации из кабинета Яндекс Бизнеса.
